아이콘

이모지를 아이콘으로 쓰지 않는다 — OS별 렌더링이 제각각이고 currentColor로 색을 물려받지 못해 배지 안에서 baseline이 흔들린다. 인라인 SVG(Lucide 계열, 1.5–2px stroke, currentColor)로 통일한다.

zap 계측기 자동 기록  ← ⚡ 대체
rotate-ccw 재제조  ← ↻ 대체
lock 결과 ← 🔒 대체 · 잠긴 탭
