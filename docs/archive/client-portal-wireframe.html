  • 화면 통합 — 공정 조회·이슈·요약·결과를 별도 페이지가 아닌 의뢰 상세 하나로. 타임라인 항목("요약 보기 →")에서 문서로 진입. 의뢰자 포털 실제 페이지 수: 대시보드 / 새 의뢰 / 의뢰 상세 / 캘린더 / 준비 가이드 = 5장.
  • 상태 히어로 — "결과가 도착했습니다" 같은 문장형 상태 표기. 기획서 4번 "상태를 스토리텔링하듯" 방향 반영.
  • 편차 노출 — 편차 발생 시 타임라인에 경고색 항목으로 삽입("편차 1건 — pH 이탈 · 조치 완료"), 탭하면 원인·조치 내역 열람 + 코멘트 가능.
  • 승인/반려 쌍 — 반려 선택 시 코멘트 필수 입력 → 상태 플로우의 "재의뢰" 경로로 진입. 승인은 서명 기록(signed_by, signed_at) 저장.
  • 모바일 — 동일 콘텐츠 세로 스택, 핵심 액션(승인)은 하단 고정 바.
