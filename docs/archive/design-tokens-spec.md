# 공유 디자인 토큰 확정 스펙
*(기획서 12번 "공유 디자인 토큰 구체값" 해소분 — 시각 자료: design-tokens.html)*

## 컨셉

Merck 2015 리브랜딩의 방향성(생동감·유기적 모티브·모노스페이스 데이터·기술 그리드)을 **pH 지시약 스펙트럼**으로 재해석. 팔레트가 도메인(버퍼 제조·pH 관리)에서 직접 유래하므로 고유성과 서사가 동시에 확보됨. 상태 색상이 곧 브랜드 색상.

## 1. 컬러 팔레트

### 뉴트럴
| 토큰 | 값 | 용도 |
|---|---|---|
| `ink` | `#17272B` | 기본 텍스트, 강조 버튼 |
| `ink-soft` | `#5C6B70` | 보조 텍스트 |
| `line` | `#D4DCDD` | 보더, 디바이더 |
| `surface` | `#FFFFFF` | 카드 배경 |
| `paper` | `#FAFAF8` | 의뢰자 포털 페이지 배경 |
| `bench` | `#EEF2F2` | 제조자 콘솔 페이지 배경 |

### 지시약 스펙트럼 (브랜드 = 상태)
| 토큰 | 값 | 유래 | 시맨틱 |
|---|---|---|---|
| `indicator-amber` | `#F0A62E` | BTB 산성(노랑) | 대기 / 주의 |
| `indicator-green` | `#3AA05F` | BTB 중성(초록) | 완료 / 승인 |
| `indicator-teal` | `#0E8290` | BTB 염기(청록) | 진행중 / 프라이머리 액션·링크 |
| `phenol-pink` | `#E14E68` | 페놀프탈레인 | 편차 / 반려 / 경고 |

- 프라이머리 컬러 = `indicator-teal`. 버튼·링크·활성 탭·현재 단계 표시에 사용
- **시그니처 요소**: 진행률 표현(스테퍼·타임라인·프로그레스)에 amber→green→teal 그라디언트 사용 — "적정이 진행될수록 색이 변한다"는 도메인 은유. 유일한 장식 요소로 제한하고 나머지는 절제

### 다크 모드 (제조자 콘솔 전용, Phase 2 후보)
`ink` ↔ 배경 반전 기반. `#101B1D` 배경 + 지시약 컬러 채도 +8%. MVP에선 토큰 구조만 준비.

## 2. 타이포그래피

| 역할 | 폰트 | 비고 |
|---|---|---|
| UI 전반 | **Pretendard Variable** | CDN 로드. 본문 400, 강조 600, 헤딩 700–800 |
| 데이터 | **JetBrains Mono** | LOT 번호, pH·부피·전도도 수치, 타임스탬프. 400/700 |

- 숫자는 Pretendard 사용 시에도 `font-variant-numeric: tabular-nums` 적용 (표·KPI 정렬)
- 타입 스케일 (모바일/태블릿 기준 px):
  - `display` 26 / 800 — 페이지 제목, 상태 히어로
  - `title` 19 / 700 — 카드·패널 제목
  - `body` 15 / 400 — 본문 (제조자 콘솔은 15 유지, 밀도는 행간으로 조절)
  - `caption` 12.5 / 400 — 메타 정보, 타임스탬프
  - `data` 15 / JetBrains Mono — 측정값 (KPI 대형은 32)

## 3. 스페이싱 · 형태

- 기본 그리드: **4px 배수**
- 스킨별 밀도:
  - 의뢰자 포털: 섹션 간격 40–48, 카드 패딩 24 — 여백 넉넉
  - 제조자 콘솔: 섹션 간격 24, 카드 패딩 16 — 정보 밀도 우선, 단 **터치 타겟 최소 44pt**
- 라운드: 카드 12, 버튼·입력 8, 배지 6, 칩 999(pill)
- 보더: 기본 1.5px `line`, 선택/강조 2px `ink`
- 그림자: 사용하지 않음(플랫). 계층은 보더와 배경 대비로 표현 — 기술 그리드 감각 유지

## 4. 컴포넌트 공통 규칙

- 상태 배지: 배경 = 지시약 컬러 12% 틴트, 텍스트 = 지시약 컬러 원색 (편차만 원색 배경 + 흰 텍스트로 최고 대비)
- 계측기 자동 기록 배지: `indicator-teal` 틴트 + ⚡ 아이콘 + JetBrains Mono 타임스탬프
- 버튼: primary = `ink` 배경 (컬러 버튼 남용 방지), 승인 액션만 `indicator-green`
- 포커스 링: `indicator-teal` 2px — 키보드 접근성

## 5. Tailwind 적용

`/packages/ui`의 `tailwind.config`에 위 토큰을 `theme.extend`로 정의, 두 앱이 preset으로 상속. 스킨 차이(배경·밀도)는 앱별 CSS 변수 오버라이드로 처리.
